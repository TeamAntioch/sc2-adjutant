You'll stage *Ashfall Relay*'s last scene, THE RELAY, on the map itself. When the Sergeant reaches the Relay Station, the game goes into Cinematic Mode: he walks to the relay mast and reports in, the camera eases up to the mast as the Adjutant answers, and the Mission ends in victory. This is a **Trigger Scene**: an in-game cutscene filmed with the Mission's own camera Anchors, with the scene's lines played as Transmissions.

Use the Workspace from [Your first Mission](/tutorials/first-mission/), with *Ashfall Relay* signed off. [A cutscene with placeholder voices](/tutorials/cutscene/) isn't needed first, but this works after it too. The turns below are written by hand. Claude's words will differ in your session, but the tool calls are the ones it makes.

Scene 2 plays when the Sergeant enters the Relay Station, the Mission's victory condition. Its stage direction is a moment on this map, the Sergeant reaching the relay, so it wants the camera on him: not bare Transmissions, and not a ping, which points at the moment but leaves the player's camera where it is. It needs no Set of its own, so it's not a Cinematic: it's a **Trigger Scene**, played on the map in Cinematic Mode. - **Skip:** Escape goes straight to the victory.

<Objective id="cameras" title="Place the mast and the cameras">

A Trigger Scene films from camera Anchors: Blueprint Anchors of kind `camera`, each with a target and the Editor's camera values. The compile writes them into the map as camera objects.

<Claude>
<ToolCall
  name="patch_blueprint"
  args={{
    mission: "ashfall-relay",
    patch: [
      { op: "add", path: "/anchors/-", value: { id: "relay-mast", name: "Relay mast", zoneId: "relay", kind: "doodad", doodadType: "LandingTower", position: { x: 86, y: 32 }, rotation: 0 } },
      {
        op: "add",
        path: "/anchors/-",
        value: {
          id: "cam-arrival", name: "Arrival", zoneId: "relay", kind: "camera", position: { x: 76, y: 32 }, cameraTarget: { x: 76, y: 32 },
          cameraValues: [{ index: "Distance", value: 14 }, { index: "Pitch", value: 30 }, { index: "Yaw", value: 180 }, { index: "FieldOfView", value: 27.8 }],
        },
      },
      {
        op: "add",
        path: "/anchors/-",
        value: {
          id: "cam-mast", name: "Mast", zoneId: "relay", kind: "camera", position: { x: 86, y: 32 }, cameraTarget: { x: 86, y: 32 },
          cameraValues: [{ index: "Distance", value: 26 }, { index: "Pitch", value: 20 }, { index: "Yaw", value: 180 }, { index: "FieldOfView", value: 27.8 }],
        },
      },
    ],
  }}
>
  places the relay mast, and two camera Anchors: a close one for the arrival and a low, wide one on the mast
</ToolCall>

The mast stands in the middle of the Relay Station. `cam-arrival` is close, at 14 distance, and lower than the game camera, at 30° pitch. `cam-mast` is a wide, nearly twice as far and lower still, at 20°, so the mast stands tall against the sky. Both face the way the game camera does, at yaw 180, with its lens, 27.8, so the scene keeps the player's sense of direction.
</Claude>

A camera Anchor's `cameraValues` are the Editor's camera object fields: `Distance` in cells, and `Pitch` (degrees down from level; the game camera's is 56), `Yaw` and `FieldOfView` in degrees. `npm run check` warns on a camera turned more than 45° from the game camera's yaw, or with another lens. Placing the mast is dressing, Stage 3's work; that comes up again at the sign-off.

</Objective>

<Objective id="shots" title="Write the shot list">

Claude writes the scene's shot list in `missions/ashfall-relay/trigger-scenes/relay.json`, with the plan, its reasons and the checks in `missions/ashfall-relay/cutscenes.md`.

<Claude>
```json
{
  "outro": "victory",
  "shots": [
    {
      "camera": "cam-arrival", "unit": { "anchorId": "sergeant" }, "line": "Ch1_ashfall_relay_2_01",
      "orders": [{ "units": ["sergeant"], "moveTo": { "x": 83, "y": 30 } }]
    },
    {
      "camera": "cam-arrival", "unit": { "anchorId": "sergeant" }, "to": "cam-mast",
      "line": "Ch1_ashfall_relay_2_02", "pauseAfterMs": 3000
    }
  ]
}
```

Two shots, each cut at the start of its line. The first is `cam-arrival`'s values aimed at the Sergeant, wherever he came in, and it orders him to walk to the mast's foot. The second starts on that same framing, so there's no cut, and eases to `cam-mast` over the Adjutant's line, then holds 3 s. `outro: "victory"` makes it end the game: after its fade out, the victory screen follows.
</Claude>

A shot's `unit` aims its camera at a unit with its Anchor's values. It aims where the unit is at the cut, and doesn't follow him. A shot aimed at `"cue"`, the unit the scene's cue found, needs a cue that names one, such as `anchorNears`. Scene 2's `anchorEntersZone` cue names none, so the shot names the Sergeant's Anchor. A shot's `move` defaults to an ease, which leaves at speed and settles.

</Objective>

You'll make *Cinder Gate*, a 1v1 Melee Map: a map the Galaxy Editor calls Melee, laid out the way ladder maps are. You draw nothing. You answer four short questions, and Claude drafts half the map as a Melee Map Blueprint, a JSON file. The compiler turns that half 180° to make the other half, stamps the standard bases, the main ramp and its plate, checks the melee rules, and times the distances a ladder player cares about. Claude revises the draft against those numbers, then hands the map over for you to walk through in the Editor.

A Melee Map belongs to no Campaign: it can live in any folder. The tools run in a Claude Code session opened in a Workspace, so open Claude Code in the one from [Your first Mission](/tutorials/first-mission/). Without one, the same compile runs from an sc2-adjutant checkout, as `npm run compile-melee-map -- <blueprint.json> <outputDir>`.

The turns below are written by hand. Claude's words will differ in your session, but the tool calls are the ones it makes.

Each base is a town hall's spot, with `facing` the corner its mineral line wraps. The start base has none: it faces away from the main ramp.

A broken melee rule fails the compile and writes nothing: a main with a second way out, a base on its own partner, a start hall off the town-hall rule's spot. Neither counts as a revision.

<Objective id="walk-through" title="Walk it through in the Editor">

The report can't tell everything: walls, drop spots and how the map reads are for you to check. Open the map in the StarCraft II Editor with File > Open, and choose `~/sc2-maps/cinder-gate/CinderGate.SC2Map/ComponentList.SC2Components`. On Apple Silicon, open it with the fixed Editor ([the macOS Host docs](https://github.com/TeamAntioch/sc2-adjutant/blob/main/packages/plugin-host-macos/docs/macos-host.md#opening-a-map-in-the-editor) say how). Then play it with File > Test Document. Go through the skill's checklist:

- Map > Map Status says **Melee**.
- A Terran wall (Supply Depot, Barracks, Supply Depot) and a Protoss wall close the top of the main ramp, and the unbuildable plate sits at its foot.
- The natural's choke closes with a standard wall: a Protoss Gateway, Cybernetics Core and Pylon, or Zerg buildings to narrow it.
- A worker sent from the main's town hall to the natural's takes about the report's 9.6 s.
- Each base's minerals and geysers look right, and a town hall fits on its spot.
- No ground that only air can reach sits beside a main or natural, and no low ground under a mineral line gives a Reaper or a Siege Tank a perch.
- Ramps and cliffs read clearly from the default camera and the minimap.

Note what you'd change, then close the map before you ask for it: rewriting a map the Editor has open can crash it.

</Objective>

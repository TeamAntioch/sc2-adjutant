# Cinematic sets

Generated by `npm run catalog-sets` from 336 Cutscene Editor files (Blizzard's game data); don't edit by hand. `catalog.json` has every occurrence: file, pieces, marks, cameras, Lights and display feeds. Screen channels gives the render-to-texture channels the set's screens show, from core's `data/display-channels.json`, which records the game's models only (`?`: none known, and some models weren't read).

A set is a cluster of scenery in one file (pieces closer than 15 units), merged with clusters in other files that share most of their models. Marks and cameras are the ones within 10 units of its scenery in the richest file. The plans are top-down from that file. They aren't pictures: the files give each piece's origin, not its size.
